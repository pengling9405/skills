# The Minimalist Entrepreneur 中文整理版

> 说明：这是 `slavingia/skills` 的中文整理版入口文档。英文原文保持不变。

## 这是什么

这是基于 Sahil Lavingia 的《The Minimalist Entrepreneur》整理出来的一组 Claude Code skills。

核心思想不是“先做产品”，而是：

- 先找到你真正服务的社群
- 先验证问题是否值得解决
- 先手工交付价值
- 先收费
- 再流程化、产品化、增长化

## 安装方式

### 在 Claude Code 中安装

```text
/plugin marketplace add slavingia/skills
/plugin install minimalist-entrepreneur
```

安装完成后，Claude Code 会自动注册这 10 个 skill。

### 本地克隆方式

```bash
git clone https://github.com/slavingia/skills.git ~/.claude/plugins/skills
```

然后在 Claude Code 中执行：

```text
/plugin marketplace add ~/.claude/plugins/skills
/plugin install minimalist-entrepreneur
```

## 技能 一览

| Skill | 命令 | 适用场景 |
|------|------|---------|
| Find Community | `/find-community` | 还在找方向，想先从社群和问题出发 |
| Validate Idea | `/validate-idea` | 想验证一个商业点子是否值得继续 |
| MVP | `/mvp` | 想做第一个最小可行产品，但范围拿不准 |
| Processize | `/processize` | 想先手工交付价值，而不是立刻写代码 |
| First Customers | `/first-customers` | 已经有产品或服务，想拿下前 100 个客户 |
| Pricing | `/pricing` | 想确定定价或调整价格 |
| Marketing Plan | `/marketing-plan` | 已有基础付费用户，想通过内容做增长 |
| Grow Sustainably | `/grow-sustainably` | 在做支出、招聘、融资、扩张决策 |
| Company Values | `/company-values` | 想定义文化和价值观，或准备招聘 |
| Minimalist Review | `/minimalist-review` | 想用极简创业原则检查某个商业决策 |

## 极简创业路径

这套 skill 的推荐顺序是：

1. **Community**：先找到你的社群
2. **Validate**：确认问题值得解决
3. **Build**：先做最小价值交付
4. **Processize**：把手工交付流程化
5. **Sell**：一个一个拿下前 100 个客户
6. **Price**：从第一天开始收费
7. **Market**：通过内容建立受众
8. **Grow**：保持可持续与盈利
9. **Culture**：建设你想长期生活其中的公司
10. **Review**：用极简原则审视每个决策

## 适合谁

这套技能尤其适合：

- solo founder
- 还在找 PMF 的 builder
- 不想一开始就陷入大规模 build 的创业者
- 想从“社群 / 问题 / 付费意愿”出发做产品的人
